# Подключение MongoDB Atlas

В корне проекта подготовлен `.env.local`. Он исключён из Git.
Для нового клона скопируйте `.env.example` в `.env.local`.

1. В Atlas откройте кластер → Connect → Drivers → Node.js.
2. Вставьте строку подключения в `MONGODB_URI` в `.env.local`.
3. Замените `<db_password>` паролем пользователя базы данных. Если в строке
   остались другие заполнители, замените и их. Спецсимволы в имени пользователя
   и пароле должны быть URL-кодированы, например `@` → `%40`, `$` → `%24`.
   Не кодируйте всю строку подключения.
4. Оставьте `MONGODB_DB=task_manager`: модуль явно выбирает эту базу независимо
   от имени базы в URI. MongoDB создаст её при первой записи.
5. В Atlas разрешите свой текущий IP в Network Access и убедитесь, что
   пользователь БД имеет права чтения и записи для `task_manager`.
6. Перезапустите `npm run dev` после изменения переменных окружения.

Не коммитьте `.env.local`, не публикуйте URI и не используйте префикс
`NEXT_PUBLIC_` для секретов. `.env.example` содержит только пустой URI и имя БД.

## Использование в серверном коде

```ts
import { getDatabase } from '@/lib/mongodb'

const db = await getDatabase()
await db.command({ ping: 1 })
```

Модуль предназначен для Node.js runtime, не для Edge или Client Components.
`server-only` запрещает импорт в клиентский код. Подключение создаётся при
первом вызове, поэтому фронтенд и сборка работают без заполненного URI.
Одновременные запросы используют общий клиент и пул соединений; при ошибке
подключения следующий вызов может повторить попытку. Не закрывайте общий
клиент после каждого запроса и не возвращайте исходные ошибки драйвера клиенту.

На этом этапе интерфейс продолжает хранить задачи в localStorage.
Модели, API и авторизация ещё не подключены. Настоящее соединение с Atlas
нужно отдельно проверить после заполнения `.env.local`.

Документация драйвера: https://www.mongodb.com/docs/drivers/node/current/connect/mongoclient/
