# Tasks API

Все endpoint’ы требуют действующую `task_manager_session` cookie и работают
только с задачами текущего пользователя.

- `GET /api/tasks` — список задач.
- `POST /api/tasks` — создаёт задачу (`text`, `priority`, `category`, `dueDate`).
- `PATCH /api/tasks/:id` — изменяет текст, статус, приоритет, категорию или дату.
- `DELETE /api/tasks/:id` — удаляет одну задачу.
- `DELETE /api/tasks` — удаляет все завершённые задачи текущего пользователя.

Идентификаторы — MongoDB ObjectId в строковом виде. Задачи хранят `userId`,
поэтому запрос не может прочитать или изменить задачи другого пользователя.
Интерфейс больше не сохраняет задачи в `localStorage`; там остаётся только тема.

Категории управляются отдельно: `GET /api/categories`, `POST /api/categories`
и `DELETE /api/categories/:name`. Удаление категории не удаляет задачи, которые
раньше её использовали.
